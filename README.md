# El Poder de la Cruz

Landing responsive construida con React y Vite a partir del diseño de Figma proporcionado.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Luego abrí la dirección local que muestra Vite en la terminal.

## Estructura rápida

- `src/App.jsx`: componentes y contenido de la página.
- `src/styles.css`: tokens visuales, layout y adaptación móvil.
- `public/assets`: imágenes y vectores exportados desde Figma.

Para reemplazar textos o enlaces, buscá la sección correspondiente en `src/App.jsx`. Para cambiar colores globales, editá las variables declaradas al principio de `src/styles.css`.
